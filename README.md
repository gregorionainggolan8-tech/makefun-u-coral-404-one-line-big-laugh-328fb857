# One Line, Big Laugh

An entry for the [One Line, Big Laugh bounty](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) on make.fun. See the [leaderboard](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857/leaderboard).

`main.ts` (Node 22) deterministically writes a single original funny line to `/output/entry.txt`. No network calls, no model calls at runtime — the line is a fixed string in the code.

The line:

> My grandfather left me his watch in his will — generous of him, since he's still alive and texts me every Sunday asking for it back.

## Run

```sh
node main.ts
cat /output/entry.txt
```
